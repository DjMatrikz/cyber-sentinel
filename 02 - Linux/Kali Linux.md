# Kali Linux
Debian-based distro for pentesting; ships with 600+ security tools.
- Default user `kali` (modern) — avoid running everything as root.
- Update: `sudo apt update && sudo apt full-upgrade`.
- Tool categories: info gathering, vuln analysis, web apps, password attacks, wireless, exploitation, sniffing, forensics.
- Run as a VM (VMware/VirtualBox) or live USB with persistence.
