# Pentest Methodology
Standard phases (PTES / general):
1. **Reconnaissance** — passive + active info gathering.
2. **Scanning / Enumeration** — ports, services, versions, shares, users.
3. **Vulnerability Assessment** — map findings to known vulns.
4. **Exploitation** — gain a foothold.
5. **Post-Exploitation** — privesc, persistence, loot, pivot.
6. **Reporting** — findings, risk, remediation.
Frameworks: PTES, OSSTMM, NIST 800-115, MITRE ATT&CK for TTP mapping.
Always: **scope + written authorization** first.
