# Security Monitoring
Continuous watch for threats across endpoints, network, cloud.
- **Telemetry sources:** logs (Windows Event, syslog, Sysmon), netflow, EDR, firewall, DNS.
- **Baseline normal** -> alert on deviation.
- **Coverage:** map detections to MITRE ATT&CK (what can you actually see?).
- Feeds a SIEM/SOC workflow: detect -> triage -> investigate -> respond.
