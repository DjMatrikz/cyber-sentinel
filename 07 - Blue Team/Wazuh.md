# Wazuh
Free, open-source SIEM/XDR (fork of OSSEC).
- Agents on endpoints -> manager -> dashboard (OpenSearch).
- **Capabilities:** log analysis, file integrity monitoring (FIM), rootkit detection, vuln detection, SCA (config audit), MITRE mapping.
- Great homelab SOC — pairs with your Docker setup.
- Rules + decoders drive alerts; integrates threat intel.
