# Azure Security
- **Entra ID** (formerly Azure AD) — identity. Conditional Access, MFA, PIM.
- **RBAC** — roles at subscription/resource-group/resource scope.
- **Defender for Cloud** — posture + threat protection. **Sentinel** — SIEM.
- **Risks:** over-privileged roles, exposed storage, legacy auth, misconfigured NSGs.
- Logs: Activity Log, sign-in logs. See [[Microsoft Entra ID]].
