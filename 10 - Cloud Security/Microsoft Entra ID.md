# Microsoft Entra ID
Cloud identity/IAM (was Azure AD).
- **Objects:** users, groups, service principals, app registrations.
- **Security:** MFA, Conditional Access policies, Privileged Identity Management (just-in-time admin), Identity Protection (risk-based).
- **Attacks:** password spray, consent phishing (illicit OAuth grants), token theft.
- **Monitor:** sign-in logs (4624-equivalent), risky sign-ins.
Ties into your Power Automate / M365 work.
