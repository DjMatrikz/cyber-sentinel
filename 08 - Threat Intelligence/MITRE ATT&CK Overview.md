# MITRE ATT&CK Overview
Knowledge base of adversary TTPs. **Tactics** (why) -> **Techniques** (how) -> sub-techniques.
- 14 enterprise tactics: Recon, Resource Dev, Initial Access, Execution, Persistence, Priv Esc, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, C2, Exfiltration, Impact.
- Technique IDs like T1003 (OS Credential Dumping), T1557 (Adversary-in-the-Middle).
- Uses: detection coverage mapping, threat modeling, red/blue alignment, reporting.
Full technique library is in your `mitre_attack/` folder.
