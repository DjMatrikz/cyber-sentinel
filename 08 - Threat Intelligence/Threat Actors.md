# Threat Actors
- **Types:** nation-state (APT), cybercrime/ransomware, hacktivist, insider, script kiddie.
- **APT naming:** vendors differ (APT29 / Cozy Bear / Midnight Blizzard = same group).
- **Motivation:** espionage, financial, disruption, ideology.
- Track via MITRE ATT&CK Groups, threat intel reports (Mandiant, CrowdStrike).
- Map actor -> known TTPs -> build detections.
