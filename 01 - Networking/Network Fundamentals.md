# Network Fundamentals
- **LAN / WAN / MAN** — local, wide, metropolitan networks.
- **OSI model (7 layers):** Physical, Data Link, Network, Transport, Session, Presentation, Application. Mnemonic: Please Do Not Throw Sausage Pizza Away.
- **TCP/IP model (4):** Link, Internet, Transport, Application.
- **Bandwidth vs throughput vs latency** — capacity vs actual rate vs delay.
- **Half vs full duplex** — one-way-at-a-time vs simultaneous.
- **Unicast / broadcast / multicast / anycast** — one-to-one / all / group / nearest.
