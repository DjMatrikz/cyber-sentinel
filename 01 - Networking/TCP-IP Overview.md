# TCP/IP Overview
## TCP vs UDP
- **TCP:** connection-oriented, reliable, ordered, 3-way handshake (SYN, SYN-ACK, ACK). Web, email, file transfer.
- **UDP:** connectionless, fast, best-effort. DNS, DHCP, VoIP, streaming.
## Key fields
- TCP flags: SYN, ACK, FIN, RST, PSH, URG.
- Ports: 0-1023 well-known, 1024-49151 registered, 49152+ dynamic.
