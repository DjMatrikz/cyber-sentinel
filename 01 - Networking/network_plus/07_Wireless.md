# Wireless (Wi-Fi) Standards & Security

## 802.11 standards
| Standard | Wi-Fi name | Band | Max speed |
|----------|-----------|------|-----------|
| 802.11a | — | 5 GHz | 54 Mbps |
| 802.11b | — | 2.4 GHz | 11 Mbps |
| 802.11g | — | 2.4 GHz | 54 Mbps |
| 802.11n | Wi-Fi 4 | 2.4/5 GHz | 600 Mbps |
| 802.11ac | Wi-Fi 5 | 5 GHz | ~3.5 Gbps |
| 802.11ax | Wi-Fi 6/6E | 2.4/5/6 GHz | ~9.6 Gbps |

- **2.4 GHz** — longer range, more interference, non-overlapping channels 1, 6, 11.
- **5 GHz** — faster, shorter range, more channels.

## Wireless security (weakest → strongest)
WEP (broken) → WPA (TKIP) → WPA2 (AES/CCMP) → **WPA3 (SAE)**.
- **WPA2-Personal** = pre-shared key (PSK). **WPA2-Enterprise** = 802.1X / RADIUS auth.
