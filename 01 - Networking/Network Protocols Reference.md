# Network Protocols & Common Ports
|Port|Proto|Purpose|
|----|-----|-------|
|20/21|FTP|file transfer|
|22|SSH/SFTP|secure shell|
|23|Telnet|insecure remote|
|25|SMTP|send mail|
|53|DNS|name resolution|
|67/68|DHCP|addressing|
|80|HTTP|web|
|110|POP3|receive mail|
|123|NTP|time|
|143|IMAP|receive mail|
|161/162|SNMP|management|
|389|LDAP|directory|
|443|HTTPS|secure web|
|445|SMB|Windows shares|
|636|LDAPS|secure LDAP|
|3389|RDP|remote desktop|
Secure swaps: Telnet->SSH, HTTP->HTTPS, FTP->SFTP, LDAP->LDAPS.
