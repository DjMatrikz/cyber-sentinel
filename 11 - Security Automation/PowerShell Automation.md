# PowerShell Automation
- Automate Windows/AD/M365 admin + security tasks.
- `Invoke-RestMethod` for APIs; `Get-WinEvent` for log parsing; scheduled tasks for cron-like jobs.
- Security uses: pull sign-in logs, automate reports, bulk user actions, parse event logs for IOCs.
- Ties directly to your Flash-reports automation and Power Automate work.
