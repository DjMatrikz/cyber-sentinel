# SOAR (Security Orchestration, Automation & Response)
Automates SOC workflows/playbooks.
- **Trigger** (alert) -> **enrich** (query threat intel) -> **decide** -> **act** (isolate host, block IP, open ticket).
- Platforms: Splunk SOAR (Phantom), Tines, Shuffle (open source), Cortex XSOAR.
- Goal: reduce analyst toil + response time (MTTR).
- Playbooks = automated IR runbooks.
