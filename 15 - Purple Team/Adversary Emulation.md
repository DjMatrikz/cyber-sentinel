# Adversary Emulation
Reproduce real attacker TTPs to validate detections.
- **Atomic Red Team** — small, scriptable tests mapped to ATT&CK techniques.
- **MITRE Caldera** — automated adversary emulation.
- **Threat-informed:** emulate a specific actor's known TTPs.
- Workflow: pick technique -> execute atomic -> verify alert fired -> fix gap.
