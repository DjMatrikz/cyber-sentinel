# CyberVault

A personal, growing cybersecurity knowledge base — organized for study (Network+, Security+) and hands-on lab work, and built to feed a local AI assistant via RAG.

Structured in [Obsidian](https://obsidian.md) as 16 domains plus tool references, with tags and backlinks throughout.

## What's inside
- **01-17 domains** — Networking, Linux, Windows Security, Wireless, Pentesting, Web App Security, Blue Team, Threat Intelligence, Cryptography, Cloud, Automation, Tools, Red/Purple/White Team, CTF, Career.
- **Tool references** — Nmap, Wireshark, Kismet, ESP32 Marauder, Flipper Zero, and more (commands, filters, cheat-sheets).
- **Cert notes** — Network+ fundamentals and study material.

These are concise reference notes and starting points — expand them with your own labs and course notes.

Drop those into the vault folder if you want them in your own copy or RAG index.

## Using it with a local AI (optional)
This vault pairs with a local RAG setup (Ollama + a small model) so you can ask your notes questions, fully offline. See the companion project for the code.

## How to use
1. Install [Obsidian](https://obsidian.md), then **Open folder as vault** and select this folder.
2. Start at `00 HOME`.
3. Browse by folder, tag, or the Graph view.
