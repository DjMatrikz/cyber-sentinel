# Sysinternals Suite
Microsoft's power tools (live forensics/IR):
- **Process Explorer** — super Task Manager; verify signatures, find handles/DLLs.
- **Process Monitor (Procmon)** — real-time file/registry/process activity.
- **Autoruns** — everything set to auto-start (persistence hunting).
- **TCPView** — live connections per process.
- **PsExec** — remote exec (also an attacker tool / lateral movement).
- **Sysmon** — advanced logging for SIEM (process creation, network, hashes).
