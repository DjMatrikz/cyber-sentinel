# Red Team Overview
Adversary emulation — simulate a real threat actor to test detection & response (not just find vulns like a pentest).
- **Goal:** achieve objectives (domain admin, data access) while staying undetected.
- **Longer, stealthier, scenario-driven** vs a pentest.
- **Kill chain / ATT&CK aligned:** recon -> initial access -> execution -> persistence -> privesc -> defense evasion -> cred access -> lateral movement -> collection -> C2 -> exfil.
- Tests the **blue team's** ability to detect/respond.
See [[Purple Team Overview]], [[C2 Frameworks]].
