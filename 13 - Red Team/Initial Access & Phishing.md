# Initial Access & Phishing
First foothold techniques (emulation, authorized + scoped).
- **Phishing:** pretext + payload (macro doc, HTML smuggling, link to cred harvester). Tools: GoPhish (authorized campaigns).
- **Other vectors:** exposed services, valid creds, supply chain, removable media (BadUSB).
- **Payload delivery** paired with evasion.
- **Defense/awareness:** this is why user training + email filtering + MFA matter.
