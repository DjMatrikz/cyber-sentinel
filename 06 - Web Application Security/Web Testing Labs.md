# Web Testing Labs (safe practice)
- **PortSwigger Web Security Academy** — free, best-in-class, guided.
- **DVWA** (Damn Vulnerable Web App), **OWASP Juice Shop**, **bWAPP**, **WebGoat**.
- **HackTheBox / TryHackMe** web tracks.
Run locally in Docker or on a lab VM. Never test apps you don't own/aren't authorized for.
